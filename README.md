## 🌟 Features

- **Modern & Responsive Design:** Built with Next.js 16 and Tailwind CSS v4 for a seamless experience across all devices.
- **Engaging Animations:** Utilizes **Framer Motion** and **GSAP** for fluid, high-performance interactions, including a dynamic typewriter hero section and tactile interactive components.
- **Smooth Scrolling:** Integrated with **Lenis** for a buttery-smooth, native-feeling scroll experience.
- **Working Contact Form:** Fully functional contact API powered by **Nodemailer**.
- **Dark/Light Mode:** Seamless theme switching with system preference detection using `next-themes`.
- **Type-Safe:** Written entirely in **TypeScript** for robust and error-free code.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd rejwanul-protfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Create a `.env` or `.env.local` file in the root directory to store your credentials (e.g., for the email contact form):
   ```env
   # Add your environment variables here
   EMAIL_USER=your-email@example.com
   EMAIL_PASS=your-app-password
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open the app:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your web browser.
